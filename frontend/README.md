# NEXORA Frontend (Future Milestone)

This directory is reserved for the future **React + TypeScript** web application.

### Planned Capabilities
- Interactive demand forecasting charts and timelines (7, 15, 30, 90 days)
- Inventory management dashboards (low-stock alerts, safety stock suggestions)
- Billing and order processing screens
- Shipping & fulfillment management
- Role-Based Access Control (Admin, Store Manager, Inventory Clerk, Cashier)

### Setup (Future)
When development begins on the frontend:
```bash
cd frontend
npm create vite@latest . -- --template react-ts
npm install
npm run dev
```
